# 中国地下偶像粉丝量 × 风格分布图

这是中国地下偶像团体的静态研究型可视化，当前收录 399 个团体，其中 376 个标记为确认存续。页面以粉丝量为横轴、摇滚—王道风格带为纵轴，并支持团名搜索、团体详情、微博与 Wiki 链接，以及按建团城市或主要活动城市进行省市混合筛选。

- 在线站点：<https://idol.hi-veblen.com/>
- 数据状态截点：2026-09-01
- 展示证据复核截至：2026-09-04

## 本地打开

直接打开 `index.html` 即可。站点没有服务端依赖，也不会在运行时调用微博或 Wiki 接口。

## 公开数据

`data/` 保存页面对应的规范化团体数据、编辑展示覆盖数据和微博候选证据摘要。页面默认显示确认存续团体，也可以切换为全部 399 个样本。

数据来自公开官号、公开博文、China Idols Wiki 及人工复核。风格轴是研究型分类，不是客观连续测量；弱证据推断会标注“（猜测）”，资料不足则标记为未判定。粉丝量、存续状态、成员阵容和主页可能随时间变化，使用前请结合相应官号重新核实。
